# Tiges d'achillée

Module de test du tirage du Yi Jing par la méthode des 50 tiges d'achillée, au design de MonYiJing.com.

- `index.html` : page autonome (HTML, CSS et JavaScript, textes des 64 hexagrammes inclus).
- Deux modes : « pas à pas » (chaque geste expliqué) et « fluide » (seules les divisions).

Déployé sur Vercel (projet `labo-tiges-achillee`), séparé de l'application MonYiJing.
